# Projektregler — payment-service

## Språk
Svara på svenska i det här projektet, om inte användaren själv skriver på engelska.

## Working process

### Planning
- Each feature gets its own plan file: `PLAN-<feature>.md`
- The plan describes briefly and clearly what needs to be built and why — not implementation detail
- The plan is defined together with the user before any code is written
- Open questions in the plan are resolved before implementation starts

### Implementation
- Work step by step through the plan — one step at a time
- Explain what the step does and why before writing any code
- Wait for approval before moving to the next step
- Keep each change small enough that the user can follow and understand it
